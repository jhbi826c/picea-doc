File ExpandFabricOps.cpp
========================

|exhale_lsh| :ref:`Parent directory <dir_lib_Dialect_CGRA_Transforms>` (``lib/Dialect/CGRA/Transforms``)

.. |exhale_lsh| unicode:: U+021B0 .. UPWARDS ARROW WITH TIP LEFTWARDS



Implements the expand-fabric-ops pass: rewrites integer operations the STRELA datapath has no functional unit for — power-of-two divide/remainder and the ``math`` bit-counting / absolute-value intrinsics — into branch-free sequences of fabric-native ops.
