File PredicatedStoreToSelect.cpp
================================

|exhale_lsh| :ref:`Parent directory <dir_lib_Dialect_CGRA_Transforms>` (``lib/Dialect/CGRA/Transforms``)

.. |exhale_lsh| unicode:: U+021B0 .. UPWARDS ARROW WITH TIP LEFTWARDS



Implements the predicated-store-to-select pass: removes ``scf.if`` from a compute loop, rewriting a conditional ``scf.if(cond) { affine.store v, m[i] }`` into an unconditional ``affine.store select(cond, v, m[i]), m[i]`` and if-converting a value-producing ``scf.if`` into ``arith.select``s.
