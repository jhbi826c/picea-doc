CGRA Passes

-annotate-dispatch-io

Stamp dispatch I/O metadata onto each cgra.deploy

-annotate-to-cgra

Wrap offloadable affine.for loops in cgra.deploy regions

-cgra-deploy-to-strela

Replace each cgra.deploy with the STRELA programming sequence

-conv-to-im2col

Rewrite a general 2-D convolution into im2col + a 1-D dot-product reduction

-dfg-operator-to-cgra

Lower a self-contained dfg.operator to the func.func the CGRA pipeline compiles

-expand-fabric-ops

Expand power-of-two divide/remainder and math integer intrinsics into fabric-native ALU sequences

-expand-memref-copy

Rewrite memref.copy into an affine loop nest (no memrefCopy helper)

-export-loop-dfg

Write one GraphViz .dot per innermost computation loop

-fuse-cgra-nests

Fuse an adjacent producer->consumer affine nest pair into one CGRA configuration

-generate-cgra-driver

Generate the C driver (and GR-HEEP dataset.h) for an outlined CGRA kernel

-hoist-reduction-unpack

Move per-element preprocessing of a reduction operand out of the reduction loop

-legalize-to-i32

Rewrite the module’s i8/i64 arith into i32-only sequences

-legalize-to-i32-func

Rewrite one function’s i8/i64 arith into i32-only sequences

-normalize-cgra-compare

Rewrite arith.cmpi into the fabric-supported >0 / ==0 vs zero forms

-outline-cgra-deploy

Outline a cgra.deploy and its host code into init/kernel/post

-pack-cgra-buffers

Share one buffer between intermediates whose live ranges are disjoint

-partition-cgra-dfg

Split a compute nest too large for one CGRA configuration into several, staged through temporary buffers

-predicated-store-to-select

Rewrite scf.if predicated affine.stores into affine.store of arith.select

-promote-accumulator

Rewrite an in-memory reduction accumulator (C[i][j] += …) into iter_args

-promote-alloca-to-global

Give stack buffers of an orchestrated-reduction nest static storage (memref.global)

-promote-scalar-reduction

Bufferize a top-level affine.for scalar accumulator (iter_args) into a 1-element memref

-promote-shared-buffers

Promote buffers streamed by more than one cgra.deploy to memref.global

-split-reduction-bias

Split C = beta*C + reduce into a zero-seeded reduction + elementwise bias

-strela-to-llvm

Lower cgra.strela_write/read to volatile llvm.store/load

-strip-stage-prints

Drop printf calls from outlined interleaved host stages (measurement builds)

Options

-include-post : Also drop the printf calls in the final host segment (*_post), so a measurement run reaches the driver's SUCCESS/FAIL verdict as well as its cycle counts

-unroll-lanes

Unroll-and-jam a compute nest by as many lanes as the fabric stream budget allows

-widen-storage-to-i32

Retype i8/i16 memref storage to i32 with load/store boundary casts
