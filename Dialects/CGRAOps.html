‘cgra’ Dialect

An MLIR dialect for CGRA deployment

This dialect transforms regular MLIR code to make it suitable for CGRA accelerators. It detects max operations, non-i32 operations, and annotates the target code. It also performs loop-level optimizations such as unrolling, fusion, and tiling.

Operations

cgra.deploy (cgra::DeployOp)

Mark a region for CGRA deployment

Syntax:

operation ::= `cgra.deploy` (`ins` `(` $streams^ `:` type($streams) `)`)? $body attr-dict
              (`:` type($results)^)?

Wraps a loop nest that is to be offloaded to the CGRA accelerator.

The streams operands are the memrefs the kernel reads and writes, passed to the region as block arguments so the data flow is explicit rather than captured. getStreams() is the single source of truth for the CGRA passes.

input_args / output_args / inout_args record which streams are read, written, or both; dispatch_size is the product of the body’s constant loop bounds. All are set by --annotate-dispatch-io.

Traits: SingleBlockImplicitTerminator<YieldOp>, SingleBlock

cgra.strela_read (cgra::StrelaReadOp)

Volatile 32-bit MMIO read from a named STRELA register

Syntax:

operation ::= `cgra.strela_read` $reg (`[` $channel^ `]`)? attr-dict `:` type($value)

A single 32-bit volatile load from one STRELA control register (e.g. “STRELA_STATUS”), used by the completion spin-wait. Lowers to llvm.load.

MemRead, not Pure: the value changes between reads, so it must not be CSE’d or hoisted out of the spin-wait.

Interfaces: MemoryEffectOpInterface (MemoryEffectOpInterface)

Effects: MemoryEffects::Effect{MemoryEffects::Read on ::mlir::SideEffects::DefaultResource}

cgra.strela_write (cgra::StrelaWriteOp)

Volatile 32-bit MMIO write to a named STRELA register

Syntax:

operation ::= `cgra.strela_write` $reg (`[` $channel^ `]`)? `,` $value attr-dict `:` type($value)

A single 32-bit volatile store to one STRELA control register, named symbolically by reg (e.g. “STRELA_CTRL”) plus an optional channel for the per-lane IMN/OMN registers. The MMIO base/offset is resolved when lowering to llvm.store, so the register layout never appears in the IR.

MemWrite keeps it from being deleted as dead or reordered against the rest of the programming sequence.

Interfaces: MemoryEffectOpInterface (MemoryEffectOpInterface)

Effects: MemoryEffects::Effect{MemoryEffects::Write on ::mlir::SideEffects::DefaultResource}

cgra.yield (cgra::YieldOp)

Terminator for a cgra.deploy region

Syntax:

operation ::= `cgra.yield` attr-dict ($operands^ `:` type($operands))?

Implicit single-block terminator of a cgra.deploy region. It carries the region’s optional results and is elided when it has no operands. Only valid directly inside a cgra.deploy.

Traits: AlwaysSpeculatableImplTrait, HasParent<DeployOp>, Terminator

Interfaces: ConditionallySpeculatable, NoMemoryEffect (MemoryEffectOpInterface)

Effects: MemoryEffects::Effect{}
