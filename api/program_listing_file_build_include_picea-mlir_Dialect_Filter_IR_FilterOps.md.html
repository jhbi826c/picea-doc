# 'filter' Dialect

The `filter` dialect groups together a set of operations that are
DSP filters used in the DPE use case, which includes FIR, IIR and
a few sampling functions.


## Operations

### `filter.envelope` (filter::EnvelopeOp)

_Defines an envelope filter with specific style._

The `envelope` operation computes an envelope of the `input` signal
using a sliding-window pooling strategy. The window advances by `step`
samples at a time, and each window of `window_size` samples is reduced
according to `style` (e.g., MA, RMS). The output size is
`(input_size - window_size) / step + 1`.
Example:
```
%env_0 = filter.envelope %input { window_size=16, step=8 }
    style=rms : tensor<256xf32> -> tensor<31xf32>
```

### `filter.fir` (filter::FIROp)

_Defines an 1-D FIR filter._

The `fir` operation computes a 1-D finite impulse response (FIR) filter
by convolving the `input` signal with the `coefficient` vector.
The result `filtered` has the same type as `input`.
Example:
```
%fir_0 = filter.fir %input coeff=%coeff
    : tensor<Nxtype> <-> tensor<Mxtype>
```

### `filter.sos` (filter::SOSOp)

_Defines a second-order-section IIR filter._

The `sos` operation computes an infinite impulse response (IIR) filter
as a cascade of second-order sections (biquad stages).
Each row of `coefficient` holds five values `[b0, b1, b2, a1, a2]`
for one section. The optional `scale` vector supplies
`num_sections + 1` gain factors applied before the first section,
between consecutive sections, and after the last section.
The result `filtered` has the same type as `input`.
Example:
```
%sos_0 = filter.sos %input coeff=%coeff
    : tensor<Nxtype> <-> tensor<Sx5xtype>
%sos_1 = filter.sos %input coeff=%coeff scale=%scale
    : tensor<Nxtype> <-> tensor<Sx5xtype>, tensor<(S+1)xtype>
```
