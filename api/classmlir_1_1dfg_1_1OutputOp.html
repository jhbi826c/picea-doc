::llvm::LogicalResult verify()

Verifies that the OutputOp operands match the enclosing OperatorOp’s output port types.

Checks that the number of operands equals the number of output ports on the parent OperatorOp and that each operand type matches the corresponding port type in order. Mismatches are hard errors because they represent a type-unsafe connection between the operator body and its output channels.
