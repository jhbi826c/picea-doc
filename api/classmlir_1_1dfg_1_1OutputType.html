Creates an OutputType for a scalar element type with no shape dimensions.

This is the simplest form of OutputType where the channel carries a single scalar value of the given elementType. Equivalent to calling OutputType::get({}, elementType).

Creates an OutputType with an explicit shape and element type.

The shape defines the number of elements along each dimension. All dimensions must be static (non-negative). Pass an empty shape for a scalar channel.

Creates an OutputType from an existing ShapedType.

Convenience builder that decomposes shapedType into its shape and scalar element type, then constructs the corresponding OutputType. Useful when adapting memref or tensor types to DFG channel types.
