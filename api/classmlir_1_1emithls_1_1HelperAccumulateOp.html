Parses a emithls::HelperAccumulateOp from its custom assembly syntax.

The expected syntax is: 

`emithls.helper_accumulate` accumulator-ref `at` `[` index-list `]`
  operator-code value `:` memref-or-array-type (`cast` value-type)?

The element type of memref-or-array-type is used to resolve value, unless an explicit trailing cast value-type overrides it — needed when the accumulate increment was computed at a different precision than the accumulator. All index operands are resolved as index type.
