Creates an InputType for a scalar element type with no shape dimensions.

This is the simplest form of InputType where the channel carries a single scalar value of the given elementType. Equivalent to calling InputType::get({}, elementType).

Creates an InputType with an explicit shape and element type.

The shape defines the number of elements along each dimension. All dimensions must be static (non-negative). Pass an empty shape for a scalar channel.

static InputType get(ShapedType shapedType)

Creates an InputType from an existing ShapedType.

Convenience builder that decomposes shapedType into its shape and scalar element type, then constructs the corresponding InputType. Useful when adapting memref or tensor types to DFG channel types.
