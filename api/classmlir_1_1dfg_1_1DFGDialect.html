class DFGDialect : public mlir::Dialect

The dfg dialect groups together a set of types, operations and transformations that are useful to implement a structured abstraction on dataflow graphs.

These abstractions are useful for constructing KPN/SDF-like dataflow graphs, which include definitions of nodes, edges and their connections.
