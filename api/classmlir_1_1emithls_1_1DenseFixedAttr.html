static ::mlir::Attribute parse(::mlir::AsmParser &odsParser, ::mlir::Type odsType)

Parses an emithls::DenseFixedAttr from its custom assembly syntax.

The expected syntax is: 

`dense_fixed` `<` type `=` data `>`

type must be a statically-shaped ShapedType whose element type is a FixedType; data is parsed as a DenseIntElementsAttr of signless integers matching the element bit width.
