class Base2ToEmitHLSTypeConverter : public TypeConverter

Type converter from base2 types to their emithls equivalent, including base2::FixedType and any container type that may wrap it (memref, the emithls array/stream/pointer types, dfg input/output ports), plus unrealized-cast materializations for values still crossing a boundary with an operation that has not been legalized yet.
