Builds a emithls::HelperLineBufferOp.

Parameters:

  • tokenRef – The shift-register token memref/array that backs the line buffer storage.

  • index – The current pixel index selecting which line to retain.

  • linebufType – The type of the resulting line buffer memref/array.

  • numChan – Per-dimension channel counts stored per pixel position.

  • numLine – Number of lines held simultaneously in the buffer.

Parses a emithls::HelperLineBufferOp from its custom assembly syntax.

The expected syntax is: 

`emithls.helper_line_buffer` token-memref

  `keep` index `:` token-type `->` linebuf-type
