static ::mlir::ParseResult parse(::mlir::OpAsmParser &parser, ::mlir::OperationState &result)

Parses an emithls::IfOp from its custom assembly syntax.

The expected syntax is: 

`emithls.if` condition-value then-region [`else` else-region]

The condition must be of i1 type. The else keyword and region are optional; when absent the false path is a no-op.
