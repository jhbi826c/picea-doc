Builds a filter::EnvelopeOp with the given input and pooling parameters.

Parameters:

  • input – The 1-D input signal tensor.

  • filteredType – The type of the 1-D output tensor.

  • windowSize – Number of samples in each pooling window.

  • step – Stride between consecutive windows.

  • style – Envelope style (e.g., MA, RMS).
