static ::mlir::ParseResult parse(::mlir::OpAsmParser &parser, ::mlir::OperationState &result)

Parses a dfg::PushOp from its custom assembly syntax.

The expected syntax is: 

`dfg.push` %token `to` %writePort (`[` index-list `]`)? `:` port-type

The to keyword separates the written value from the destination port. Index operands, if present, address a specific element of a shaped port. The token type is resolved as the element type of the port and is not written explicitly.
