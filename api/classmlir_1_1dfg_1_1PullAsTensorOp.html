Builds a dfg::PullAsTensorOp that reads an entire shaped port as a ranked tensor.

The result type is a RankedTensorType whose shape and element type are taken from the dfg::OutputType of readPort.

Parameters:

static ::mlir::ParseResult parse(::mlir::OpAsmParser &parser, ::mlir::OperationState &result)

Parses a dfg::PullAsTensorOp from its custom assembly syntax.

The expected syntax is: 

`dfg.pull_as_tensor` %readPort `:` port-type

No index list is accepted because this operation always reads the full shaped extent of the port. The result type (a RankedTensorType) is derived from the port type and is not written explicitly.
