# 'base2' Dialect

The `base2` dialect groups together a set of types, operations and
interfaces that abstracts binary representations of numbers in both
fixed-point and floating point formats.

## Attributes

### BitsAttr

_Constant bit sequence attribute_

Syntax:

```
#base2.bits<
  ::mlir::Type,   # type
  BitSequence   # value
>
```

The `bits` attribute represents a compile-time constant sequence of bits
that defines the value of a `BitSequenceType`.

Syntax:

```
bits-attr    ::= `bits` `<` bit-sequence `>` `:` type
bit-sequence ::= `"` bit-literal (trunc-spec)? `"`
bit-literal  ::= `0b` [_01]* | `0x` [_0-9a-fA-F]*
trunc-spec   ::= `/` [0-9]+
```

The number of bits in the bit-sequence must be equal to the bit width
of the type.

Example:

```
// These all have the same value.
#base2.bits<"0b0000001000"> : i10
#base2.bits<"0b1000/10"> : i10
#base2.bits<"0x8/10"> : i10
#base2.bits<"0x0008/10"> : i10
#base2.bits<"0x000008/10"> : i10

// And this is the canonical version of the same value.
#base2.bits<"0x08/10"> : i10
```

| type | `::mlir::Type` |  |
| value | `BitSequence` |  |

### DenseBitsAttr

_Constant densely-packed bit sequence container attribute_

The `dense_bits` attribute represents a compile-time constant container
of sequences of bits that each define the value of a common
`BitSequenceType` element type.

Syntax:

```
dense-bits-attr ::= `dense_bits` `<` $type `=` $data `>`
```

The result type must be a shaped type of `BitSequenceType` elements,
and the dense elements contained must match the shape of type, or be a
splat.

Example:

```
// These all have the same value.
#base2.dense_bits<tensor<3xi10> = dense<1>>
#base2.dense_bits<tensor<3xi10> = dense<[1, 2, 3]>>
#base2.dense_bits<tensor<3xi10> = dense<"0x010002000300">>
```

| :-------: | :-------: | ----------- |
| type | `::mlir::Type` |  |

## Types

### FixedType

_Fixed-point number type_

Syntax:

```
!base2.fixed<
  unsigned,   # integerBits
  unsigned   # fractionalBits
>
```

The `base2.fixed` type stores a fixed-point rational number using the
specified number of `$integerBits` and `$fractionalBits`, which sign
bit is implicit.

Example:

```
fixed-type ::= `fixed` `<` $integerBits `,` $fractionalBits `>`
```

#### Parameters:

| Parameter | C++ type | Description |
| :-------: | :-------: | ----------- |
