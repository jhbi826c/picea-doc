static ::mlir::ParseResult parse(::mlir::OpAsmParser &parser, ::mlir::OperationState &result)

Parses an emithls::UpdateOp from its custom assembly syntax.

The expected syntax is: 

`emithls.update` variable [`[` index-list `]`]
  `with` new-value [`[` index-list `]`]
  `:` variable-type `<-` new-value-type

Both index lists are optional; when absent the assignment targets or sources the variable/value as a whole. The operandSegmentSizes attribute is derived from the parsed operand counts and stored automatically.
