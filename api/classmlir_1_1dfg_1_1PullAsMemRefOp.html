The result type is a MemRefType whose shape and element type are taken from the dfg::OutputType of readPort.

Parameters:

Parses a dfg::PullAsMemRefOp from its custom assembly syntax.

The expected syntax is: 

`dfg.pull_as_memref` %readPort `:` port-type

Mirrors PullAsTensorOp::parse; the memref result type is derived from the port type and is not written explicitly.
