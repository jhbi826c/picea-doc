Parses a dfg::PushMemRefOp from its custom assembly syntax.

The expected syntax is: 

`dfg.push_memref` %tokenMemref `to` %writePort `:` port-type

The memref token type is resolved as a MemRefType derived from the port’s shape and element type and is not written explicitly.
