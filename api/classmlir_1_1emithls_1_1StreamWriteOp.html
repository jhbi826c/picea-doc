Verifies an emithls::StreamWriteOp has consistent stream and data types.

When the operand is an ArrayType, its element must be a StreamType and the number of indices must match the array rank. For a plain StreamType no indices are allowed. In both cases the stream’s element type must equal the type of the data operand.
