Canonicalization patterns for IncludeOp.

  • RemoveSameInclude: removes the IncludeOp with the same header string as one defined before.

  • HoistIncludeToTop: moves all IncludeOp within ModuleOp to the top.

  • ReorderIncludes: reorders all IncludeOp alphabetically in increasing order.
