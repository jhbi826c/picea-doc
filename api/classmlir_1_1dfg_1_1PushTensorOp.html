static ::mlir::ParseResult parse(::mlir::OpAsmParser &parser, ::mlir::OperationState &result)

Parses a dfg::PushTensorOp from its custom assembly syntax.

The expected syntax is: 

`dfg.push_tensor` %tokenTensor `to` %writePort `:` port-type

The tensor token type is resolved as a RankedTensorType derived from the port’s shape and element type and is not written explicitly.
