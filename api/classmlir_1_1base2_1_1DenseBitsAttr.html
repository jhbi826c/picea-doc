static ::mlir::Attribute parse(::mlir::AsmParser &odsParser, ::mlir::Type odsType)

Parses a base2::DenseBitsAttr from its custom assembly syntax.

The expected syntax is: 

`dense_bits` `<` type `=` data `>`

type must be a statically-shaped ShapedType whose element type is a BitSequenceType; data is parsed as a DenseIntElementsAttr of signless integers matching the element bit width.
